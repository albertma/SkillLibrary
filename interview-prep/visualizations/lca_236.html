🔁 递归执行过程（后序遍历）

以 p=5, q=4 为例，看看这棵树上每个节点发生了什么：

叶子层

6 → 非p非q非空，左右子节点都None → 返回 None
7 → 同上 → 返回 None
4 → 等于 q → 返回 4（找到q，往上报告）
0 → 非p非q，左右None → 返回 None
8 → 同上 → 返回 None

中间层

2 → 非p非q，检查左右：left=None（7返回），right=4（q返回）
→ 只有right非空 → 返回 4（继续往上报告）

5 → 等于 p → 返回 5（找到p，往上报告）
1 → 非p非q，检查左右：left=None（0返回），right=None（8返回）
→ 两边都None → 返回 None

根节点

3 → 非p非q，检查左右：left=5（p所在子树），right=None（1返回None）
→ 等等，left=5 是含p的结果，right=None

临界判断：left 和 right 都非空吗？
→ left=5(非空), right=None → 不都非空
→ 执行 return left or right → 按理应该返回5...

🔄 精确追踪修正版

关键点：p=5 在节点5处直接返回，不会再往下走2、7、4。

所以节点2的子节点 实际只走了7（左），4被p=5的提前返回挡住了。

但我们的例子 p=5, q=4 中，q=4 是 p=5 的后代！

正确过程：
① 递归下到 root=3，先走左到 root=5
② root=5 等于 p → 直接返回 5，不走右子树（永远不会找到4）
③ 但算法并不需要找到4！因为 q 在 p 的子树里，p 本身 就是 LCA

✅ 答案正确：LCA(5,4) = 5

📌 核心算法（就这几行）

def lowestCommonAncestor(root, p, q):
    # ① 遇到 p 或 q 或空 → 直接返回
    if not root or root == p or root == q:
        return root

    # ② 后序：先问左右子树
    left  = lowestCommonAncestor(root.left,  p, q)
    right = lowestCommonAncestor(root.right, p, q)

    # ③ 核心判断
    if left and right:        # p在左，q在右 → root就是LCA
        return root
    return left or right       # 否则，上传非空的那一侧

💡 三种场景速查

场景1：p 和 q 分别在 root 的两侧
left 和 right 都非空 → root 就是 LCA

场景2：p 是 q 的祖先
在 p 节点就返回了（p 是 p 自己），q 在 p 的子树中 → p 就是 LCA

场景3：p 和 q 在同一侧
只有 left 或 right 非空 → 把非空的那侧继续往上传递
