# 平实语言写作规则

这些规则是硬约束。每写完一段，用它们检查一遍。

## 三条铁律

### 1. 不用黑话

黑话指：行业术语、英文缩写、网络流行语、抽象大词。

- 出现术语时，要么删掉，要么当场用一句大白话解释
- 英文缩写第一次出现必须解释，能不用就不用
- "赋能、抓手、闭环、颗粒度、底层逻辑、心智、对齐、沉淀、打法"这类词，一律换掉

改法示例：

- ❌ 我们要打造一个数据驱动的增长闭环
- ✅ 我们要每周看数据，发现哪一步用户流失最多，就改哪一步

- ❌ 这个方案可以提升团队的执行力
- ✅ 照这个方案做，第二天就能知道活分给谁、什么时候交

### 2. 不写长句

一句话超过 40 个字，就拆成两句。日常目标是 20-30 字一句。

拆句的办法：

- 一个句号里只说一件事
- 逗号超过 3 个，考虑拆句
- 连续出现两个"的"，从中间断开

改法示例：

- ❌ 那个在上周会议上被大家反复讨论过的、关于下半年要不要把资源从老产品转移到新产品上的问题，最终还是没有得出结论。
- ✅ 上周开会讨论了一个问题：下半年要不要把资源从老产品挪到新产品上。讨论了很久，最后没有结论。

### 3. 不写倒装句

主语放在句子前面。按时间顺序说话，按因果顺序说话。

- ❌ 深夜十一点，改了七版的设计稿，被客户打回来了。
- ✅ 客户在深夜十一点打回了设计稿。这已经是第七版了。

- ❌ 只有真正理解了用户，才能做出好产品。（条件前置也算倒装）
- ✅ 做出好产品的前提，是理解用户。/ 你得先理解用户，才做得出好产品。

## 补充习惯

- 多用动词，少用形容词：不写"非常优秀的成果"，写"三个月涨了十万用户"
- 数字要具体：不写"很多人"，写"100 个人里有 87 个"
- 用"你"和"我"说话，像朋友聊天
- 一个段落最多 3 行，只说一个意思
- 删掉填充词：其实、可以说、在一定程度上、值得注意的是、众所周知
- 引用别人的话必须标出处：长引文用「原话引用」块，短句在正文用「」并写明谁说的；自己的评论和别人的观点绝不混写

## 自检清单

写完全文后逐条打勾，任何一条不过就回去改：

- [ ] 全文 1800-2200 字
- [ ] 搜一遍黑话清单（赋能 / 抓手 / 闭环 / 颗粒度 / 底层逻辑 / 对齐 / 心智 / 沉淀 / 打法），一个都没有
- [ ] 最长的一句话不超过 40 字
- [ ] 没有把结果放在原因前面、把时间地点堆在主语前面的句子
- [ ] 每段不超过 3 行
- [ ] 读出声不拗口
