# 封面插图提示词公式（油画风格）

每篇文章生成一张油画风格的插图，放在正文开头。风格描述锁死，只换主体，保证整个账号的插图是一个系列。

## 固定风格（锁死，不许改）

中文版：

> 油画静物，{主体}，柔和厚重的笔触，温暖偏灰的色调，安静的室内光，居中构图，画面干净，无文字，无水印

英文版（部分生图工具英文效果更好）：

> Oil painting still life, {subject}, soft impasto brushstrokes, warm muted tones, quiet indoor light, centered composition, clean background, no text, no watermark

尺寸：正文插图 3:2（如 1536×1024）。若另需公众号头图，用同一提示词改 2.35:1（如 1200×510）再出一张。

## 标题 → 主体 的转换规则

主体默认是一组瓶插花（花材应季），再从标题提取意象，决定花材、颜色和小道具：

1. 提取标题里的具体名词（如"地铁""设计稿""修表"）
2. 提取标题的情绪：坚定 / 怀旧 / 释然 / 焦虑……
3. 花材跟着情绪走：
   - 坚持生长 → 向日葵、郁金香（挺立的花）
   - 怀旧、时间 → 干花、尤加利、旧怀表、褪色丝带
   - 释然、放下 → 掉落的花瓣、宽口浅瓶
   - 日常烟火 → 洋桔梗、小雏菊、陶罐
4. 标题里的名词变成画面道具（地铁 → 一张车票；修表 → 齿轮与镊子）

示例：

- 标题《我开始每天写 500 字》
  主体：一瓶向日葵和洋桔梗，旁边散着一支钢笔和几张手写稿纸
- 标题《把一件事做十年是什么感觉》
  主体：深色木桌上一瓶干花与尤加利，旁边一块旧怀表和散落的小齿轮

## 硬性约束

- 无文字、无水印、无 logo
- 不出现人脸
- 同一账号所有插图风格一致：只换主体，不改风格描述

## 想改成别的画面类型？

把「主体默认是一组瓶插花」这一句改掉即可。比如想要通用插图，改成"主体默认是一个与标题意象相关的场景或物件"，其余规则不变。
